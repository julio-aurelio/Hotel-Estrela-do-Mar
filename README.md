# ⭐ Hotel Estrela do Mar

Site institucional de um hotel fictício em **Búzios/RJ**, feito durante o curso para praticar HTML e CSS.

![Logo do hotel](asset/img/logo6.png)

## Seções do site

- **Home** com menu de navegação e logo do hotel (5 estrelas)
- **Quartos**: suíte individual/dupla e quarto família, com fotos e descrição
- **Restaurante**: galeria com fotos do ambiente e dos pratos de frutos do mar
- **Localização**: mapa e endereço do hotel
- **Reservas**: formulário com check-in, check-out e número de adultos e crianças
- **Canais de atendimento**: WhatsApp e e-mail no rodapé

## Tecnologias

- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/) (ícones)
- Google Fonts (Poppins e Kalam)

## Estrutura

```
├── index.html     # página do hotel
├── style.css      # estilos
└── asset/img/     # logo, fotos dos quartos, restaurante e mapa
```

## Como rodar

Não precisa instalar nada:

1. Clone o repositório
   ```bash
   git clone https://github.com/julio-aurelio/Projeto_hotel-main.git
   ```
2. Abra o `index.html` no navegador.

## O que eu aprendi

- Montar uma página com várias seções e navegação por âncoras (`#quartos`, `#reservas`...)
- Criar formulários com campos de data e número
- Usar ícones e fontes externas
